Settings reference

Everything is an environment variable with a working default. This page is generated from the Unraid template and .env.example on every deploy, so it cannot drift from the container.

Two vocabularies used below

The four *_ACTION settings take one of:

replace
Remove from queue and client, blocklist, search for a different release. The loop guard applies, so the same release title stops being re-searched after LOOP_GUARD_LIMIT blocklists.
discard
Remove from queue and client, blocklist, keep whatever is already in the library, no new search.
notify
Leave it alone and report it. The log line names the setting that would auto-clear it.

The seven NOTIFY_* category settings take one of:

immediate
Batched within a cycle and sent at the end of it.
daily, weekly, monthly
Sent at NOTIFY_DIGEST_HOUR on the configured day. Categories sharing a slot are merged into one message.
none
Never sent. Still logged.

Unraid users see the same settings as form fields; the quoted “Unraid” name is the field label. Anything not in the template can be added in the container's Edit view with “Add another Path, Port, Variable”.
